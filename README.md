# kazuhitotakao

**フリーランスエンジニア｜Webアプリケーション開発**

PHP / LaravelでのWebアプリ開発、React / TypeScriptを用いた画面実装に取り組んでいます。個人開発では、親子の公園での体験を題材にしたブラウザゲーム「こうちゃんの大冒険」を制作しています。

## 代表作品

### こうちゃんの大冒険 ― 個人開発

こうちゃんと一緒に公園を探索する、選択式のブラウザゲームです。遊びや休憩を選びながら、子どもの体力・機嫌、親の体力・余裕を考えて冒険を進めます。

- **選択と状態の変化**：行動に応じて、時間・ステータス・おでかけポイントが変化
- **中断・再開**：探索の進行を保存し、「つづきから」で再開
- **サウンドトラック**：ゲーム内の楽曲を紹介する専用ページ

[ゲームを遊ぶ](https://kouchan-game.vercel.app/) · [サウンドトラック](https://kouchan-game.vercel.app/soundtrack)

## 技術・実装経験

以下は公開リポジトリで使用している技術です。

| 分野 | 技術 | 公開コードでの実装内容 |
| --- | --- | --- |
| バックエンド | PHP / Laravel / MySQL | 認証、権限管理、予約・商品管理、CSV取り込み |
| フロントエンド | React / TypeScript / JavaScript / HTML / CSS | Markdownプレビュー、画面遷移、ブラウザ内へのデータ保存 |
| 外部サービス連携 | Stripe / AWS S3 | テスト決済、画像の保存・取得 |
| 開発環境 | Docker / Docker Compose / nginx | Webアプリの開発環境構成 |
| テスト・自動化 | PHPUnit / CircleCI | 機能テストのコード、テスト・デプロイの設定 |

React / TypeScriptの実装は、[markdown-editor](https://github.com/kazuhitotakao/markdown-editor)で公開しています。
